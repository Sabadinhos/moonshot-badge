# App Store copy

## Summary

PUMP a SOL coin across London. Three kicks, four maps, nearby scores.

## Description

↔ = Select Map
↕ = Select Character
SELECT = Kick
CANCEL = Exit

The description is short store copy, not the full control flow. In play, press and hold SELECT to start the falling coin and charge power; release near the bat. CANCEL pauses first, and quitting requires confirmation. The OS HOME button exits immediately. Nearby scores are self-reported mesh scores, not a global or verified-friends leaderboard. The code requests 1 !LAMP at 600 m and up to 5 per run at 800 m, with a requested limit of 20 per player each UTC day; !LAMPs remain inactive until DevRel grants that award cap.

`app.json` carries the summary; the Solana OS documented manifest does not list a `description` field. Paste the description into the submission form if that field is offered rather than adding an unsupported manifest key.
